# Структура расширения `ТБВыгрузказагрузка`

Документ содержит состав объектов расширения `ТБ_СопоставлениеОбъектов`
(проект `ТБВыгрузказагрузка`) и их расположение в файловой структуре проекта.
Каноническое описание логики — в `описание/Описание.md`.

## 1. Параметры конфигурации расширения

- **Имя конфигурации:** `ТБ_СопоставлениеОбъектов`
- **Синоним:** Сопоставление объектов (ТБ)
- **Префикс имён (`namePrefix`):** `ТБ_`
- **Назначение (purpose):** `AddOn`
- **Принадлежность:** `Adopted` (расширение конфигурации)
- **Режим совместимости расширения:** `8.3.16`
- **Версия платформы:** `8.3.27`
- **Вариант встроенного языка:** Русский
- **Основной режим запуска:** `ManagedApplication`
- **Назначения использования:** `PersonalComputer`
- **Интерфейс совместимости:** `TaxiEnableVersion8_2`
- **Версия расширения:** `1.0.0`
- **Родительская конфигурация:** `пустая_для_гкс` (1С:ERP УП 2, 2.5.26.118)
- **Файл описания:** `src/Configuration/Configuration.mdo`

## 2. Подсистемы (`Subsystems`)

## 3. Роли (`Roles`)

| Имя | Файл | Назначение |
|-----|------|------------|
| `ТБ_ПросмотрНастройкиЗагрузкиОбъектов` | `src/Roles/ТБ_ПросмотрНастройкиЗагрузкиОбъектов/` | Просмотр справочников источников/правил/настроек/сценариев, регистров соответствий и доступности настроек; использование обработки `ТБ_ЗагрузкаОбъектов` |

## 4. Собственные общие модули (`CommonModules`)

| Модуль | Контекст | Назначение |
|---|---|---|
| `ТБ_ЗагрузкаОбъектов` | Сервер + Внешнее соединение | Программный интерфейс загрузки объектов, выполнение сценариев, анализ отклонений |
| `ТБ_СопоставлениеОбъектов` | Сервер + Внешнее соединение | Ядро подсистемы сопоставления (свойства источника, таблицы соответствия, поиск/создание объектов, обработчики, JSON, COM) |
| `ТБ_СопоставлениеОбъектовВызовСервера` | Сервер + Вызов сервера | Серверные обёртки вызовов с клиента (`НастройкиЗагрузки`, `ЗагрузитьОбъект`) |
| `ТБ_СопоставлениеОбъектовКлиент` | Клиент (управляемое приложение) | Клиентские помощники работы с таблицами формы |
| `ТБ_СопоставлениеОбъектовПовтИсп` | Сервер + Внешнее соединение (повторное использование на сеанс) | Повторно используемые значения и COM-подключение |
