# История версий расширения `ТБВыгрузказагрузка`

Хроника изменений версий расширения `ТБ_СопоставлениеОбъектов`. Каноническое
описание архитектуры — в `Описание.md` и `Структура.md`; схема версий — в
`Версионирование.md`.

> Git-репозитория в проекте нет; история ведётся в этом файле. Новые записи
> добавлять в конец списка по возрастанию версии.

## Текущая версия

**`1.1.1`** — файл `src/Configuration/Configuration.mdo`.

## Правило версионирования

Кратко: версия расширения — `Major.Minor.Patch` (три компонента, старт `1.0.0`);
`Major` — только по явному запросу пользователя; `Minor` — новая функциональность;
`Patch` — багфиксы. Полная схема — в `Версионирование.md`.

## Выпуск 1.1.0 — 2026-10-10

- Чистка маркеров EDT: 312 → 92, ошибок 48 → 1 (единственная оставшаяся — ложноположительный `SU13` в `CommonModules/ТБ_СопоставлениеОбъектов/Module.bsl`, функция `ДанныеОбъекта`: структура собирается через `Вставить("Ключ")` без второго аргумента; проверены 7 вариантов исправления, директива `// @skip-check` ошибку не подавляет).
- Рефакторинг ядра выгрузки (`DataProcessors/ВыгрузкаЗагрузкаДанныхXMLСФильтрами/ObjectModule.bsl`): состав колонок регистров берётся из `НаборЗаписей.Выгрузить()`, обход ссылок — через объектную модель и кэш колонок (`ПостроитьКэшКолонокОбъектов` + `ОбработатьОбъектПоСсылке`), отбор констант проверяется кодом (`СоответствуетОтборуКонстанты`).
- Перенос разбора/записи XML на сервер в формах `ТБ_ИсточникиДанных/ФормаЭлемента` и `ТБ_СопоставлениеОбъектов/Форма`; `НачатьПомещениеФайла` → `НачатьПомещениеФайлаНаСервер`; безопасный режим в обработчиках сопоставления.
- Правки по стандартам: SU93/SU66 (области модулей), SU48 (документирующие комментарии), SU70/SU72/SU45, SU68/SU30/SU27/SU62; метаданные: представления 4 регистров, колонки и обработчик в `ТБ_Объекты`, пересоздание поля `ПравилоСоставления` в `ТБ_ЗагруженныеДанныеИсточника/ФормаЗаписи`.
- Тип: рефакторинг + исправления (Minor).
- **ВАЖНО:** функциональный прогон «выгрузка → загрузка» на тестовой базе НЕ выполнен — обязателен до ввода в эксплуатацию; чек-лист в `AGENTS/отчёт/Задача_ЧисткаМаркеровEDT_Остаток.md`.
- Остаток, требующий ручных правок в редакторе форм EDT: `SU115`/`SU114`/`SU118`, `SU188`, `SU88`, `SU4`, `SU44`.
- Закрыты маркеры `SU56` (23 шт.) — в доккомментариях методов `DataProcessors/ВыгрузкаЗагрузкаДанныхXMLСФильтрами/ObjectModule.bsl` восстановлен заголовок раздела `// Параметры:` и указаны типы параметров; разделы `// Возврат - …` приведены к конвенции `// Возвращаемое значение:`.
- Закрыты маркеры `SU79` (10 шт.) — завершающим обязательным параметрам методов того же модуля добавлено значение по умолчанию `= Неопределено` (аддитивно, существующие вызовы не затронуты). Для метода `ЗаписьЧерезНаборЗаписей` (строка 2057) правка не выполнялась: полное устранение потребовало бы >3 параметров по умолчанию (`SU16`), поэтому один `SU79` там оставлен осознанно.

## Выпуск 1.1.1 — 2026-10-10

- **Ошибок 1С в проекте — 0** (было 1: `SU13`). Маркеров всего 11 (было 312 на старте).
- `SU13` (единственная ошибка) — устранена: объявлены свойства структуры в доккомментариях цепочки `ДанныеОбъекта → СоздатьИзменитьОбъект → НайтиСоздатьОбъект` (`CommonModules/ТБ_СопоставлениеОбъектов`), плюс явные значения в `Вставить("Ссылка", Неопределено)`. Поведение не изменилось.
- `SU16` (7) — сняты значения по умолчанию у лишних параметров с правкой всех вызовов; `ЗаписьЧерезНаборЗаписей` (9→6 параметров) и `ПодставитьПараметрыВСтроку` (10→4) переведены на свёрнутые параметры.
- `SU239` (4) и `SU220` (8) — доступ к реквизитам переведён на индексирование/явные переменные-ключи; `SU220` в `ТБ_СопоставлениеОбъектов` (справочник с владельцем-планом видов характеристик) — вызов `НайтиПоНаименованию` заменён запросом, вынесенным в делегат `ТБ_ЗагрузкаОбъектов.НайтиЗначениеСвойстваПоНаименованию` (иначе возникали ошибки SU95).
- `SU242` (12) — литералы-имена реквизитов вынесены в локальные переменные.
- `SU4` (3) — программный `Новый Шрифт(...)` заменён на элемент стиля `ШрифтыСтиля.ЖирныйШрифт` (в серверном контексте `ЭлементыСтиля` недоступна).
- `SU50` — область `ПрограммныйИнтерфейс` → `СлужебныйПрограммныйИнтерфейс`; `SU88` — параметр формы читается по имени через переменную; `SU44` — удалён неиспользуемый метод формы.
- **ВАЖНО:** функциональный прогон «выгрузка → загрузка» на тестовой базе **НЕ выполнен** — обязателен (затронуто ядро обмена: состав колонок, обход ссылок, поиск значений свойств, безопасный режим).
- **Осталось (не закрывается кодом):** `SU61` (имена `Подключаемый_…`/`СО_…`, требуемые механизмом переопределения), `SU1`, `SU11`, `SU97`, `SU109`, `SU111` (2), `SU196`.
- `SU61` (1 из 4 закрыт): `СО_ЗаполнитьЗначенияПустыхСвойств` → `ТБ_ЗаполнитьЗначенияПустыхСвойств` (`CommonModules/ОбщегоНазначенияУТКлиентСервер`); связь с оригиналом задаётся аннотацией `&Вместо("ЗаполнитьЗначенияПустыхСвойств")`, ссылок на старое имя по коду нет.
- `SU61` по `Подключаемый_ВыполнитьПереопределяемуюКоманду` (3 формы) переименованием **не закрывается**: снятие префикса `Подключаемый_` (даже как `ТБ_Подключаемый_…`) заставляет EDT считать метод не-обработчиком команды и порождает `SU44` + `SU93` в каждом модуле, поэтому имена возвращены в исходное состояние.
- Тип: багфикс (Patch).
