# `отчёт/` — отчёты и задачи расширения `ТБВыгрузказагрузка`

Папка для отчётов о внесённых изменениях, разборов дефектов и хроник по
расширению `ТБ_СопоставлениеОбъектов`.

Правила ведения:

- Один отчёт — один файл; имя начинается с `ОТЧЁТ_`.
- Каждый добавленный файл регистрируется в
  `AGENTS/состояние/СПИСОК_MD_ФАЙЛОВ.md`.
- Краткие записи о версиях — в `AGENTS/описание/ИсторияВерсий.md`.
