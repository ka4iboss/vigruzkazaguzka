# `рецепты/` — переиспользуемые приёмы расширения `ТБВыгрузказагрузка`

Папка для приёмов и решений, полезных при дальнейшей работе с расширением
`ТБ_СопоставлениеОбъектов` (особенности платформы, обходы ошибок EDT, работа с
заимствованными объектами и т. п.).

- Основной сборник — `Рецепты.md` (заполняется по мере накопления).
- Каждый добавленный файл регистрируется в
  `AGENTS/состояние/СПИСОК_MD_ФАЙЛОВ.md`.
