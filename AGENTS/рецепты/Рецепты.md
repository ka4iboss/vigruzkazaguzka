# Рецепты и приёмы — расширение `ТБВыгрузказагрузка`

Сборник приёмов, полезных при работе с расширением `ТБ_СопоставлениеОбъектов`.
Заполняется по мере накопления; общие приёмы workspace — в
`R:\EDTProjects\GGKKSS\рецепты\`.

## 1. Заимствованные объекты ERP

- Расширение **не наследует свойства** заимствованных объектов: при маркерах
  `SU100/SU118` сверить `descriptionLength`, `hierarchical`, `hierarchyType`,
  `codeLength` с базовой конфигурацией (`пустая_для_гкс`) и привести через
  инструмент правки метаданных.
- Английские имена стандартных реквизитов в `.mdo` (`Ref`, `Description`,
  `Parent`, `DeletionMark`) — внутренняя запись EDT; рабочие имена определяются
  языком кода конфигурации (русский). Переименовывать/адаптировать их не нужно.
- Формы заимствованных объектов правятся **только** через модель EDT
  (`1C_EditMetadata`), не ручной правкой `.form`.

## 2. Длительные операции

Тяжёлые операции (загрузка объектов, поиск дублей, выполнение сценариев, загрузка
из внешнего источника) выполняются через `ДлительныеОперации` + фоновое задание с
индикацией прогресса, а не синхронно из формы. Точки применения — обработки
`ТБ_ЗагрузкаОбъектов`, `ТБ_СопоставлениеОбъектов` и команда
`ТБ_СценарииЗагрузкиОбъектов.ВыполнитьСейчас`.

## 3. Прочее

Дополняется по мере накопления опыта работы с проектом.
