# `план/` — плановые документы расширения `ТБВыгрузказагрузка`

Папка для долгосрочных планов и планов задач по расширению
`ТБ_СопоставлениеОбъектов`.

Правила ведения:

- Один план — один файл; имя начинается с `ПЛАН_` (или `ЗАДАЧА_` для задачи).
- Каждый добавленный файл регистрируется в
  `AGENTS/состояние/СПИСОК_MD_ФАЙЛОВ.md`.
- Активные задачи и техдолг — в `AGENTS/состояние/TODO.md`.
